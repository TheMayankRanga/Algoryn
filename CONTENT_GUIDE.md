# Content Guide

## How to add a new lesson or pattern

1. Update the structured dataset in src/lib/content.ts.
2. Add or reuse a visualizer component for the idea.
3. Create a route or section that surfaces the lesson in the navigation or curriculum.
4. Validate the content with npm run validate-content.

## Best practices

- Keep explanation beginner-friendly.
- Pair every concept with a visual or state change.
- Include complexity, recognition hints, and mistakes to avoid.
- Keep data separate from presentation so the app remains scalable.

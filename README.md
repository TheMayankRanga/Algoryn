# Algoryn

> See algorithms. Understand patterns. Solve problems.

Algoryn is an interactive Data Structures and Algorithms learning platform designed around one key idea: students should see algorithms execute, not just read about them.

## Features

- Interactive algorithm visualizations
- DSA lessons
- Pattern recognition
- Coding practice
- Problem explorer
- Interview preparation
- Learning roadmaps
- Progress tracking

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Validation commands

```bash
npm run lint
npm run typecheck
npm run validate-content
npm run build
```

## Project structure

- src/app: route pages
- src/components: shared UI and visualizer components
- src/lib/content.ts: structured educational datasets
- scripts/validate-content.mjs: basic content integrity checks

## Extension path

This project is designed to grow into a fuller platform with more lessons, real problem pages, and richer visualizations without rewriting the core architecture.
